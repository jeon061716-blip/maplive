웹사이트 결제 시스템 연동 가이드

💡 실제 결제 시스템 연동 가이드: 웹사이트에서 실제 주문금 결제를 처리하려면 전자결제대행사(PG사)와 연동이 필요합니다.

1. PG사 (결제대행사) 이용

토스페이먼츠, KG이니시스, NHN KCP 등과 계약 후 연동 SDK를 적용합니다. (포트원/아임포트 등을 이용하면 간편하게 작성 가능)

2. 간편결제 (카카오페이 / 네이버페이 / 토스페이)

각 플랫폼 개발자 센터에서 REST API Key를 받아 결제 창 호출 및 서버 간 결제 승인 요청을 진행합니다.

3. 현장 결제 및 가상 계좌

픽업 현장 결제는 주문 생성 후 매장 수령 시 카드/현금으로 수령하며, 가상계좌의 경우 Webhook을 통해 실시간 입금 통보를 받아 처리합니다.

* 본 애플리케이션은 결제 모의 시뮬레이션을 내장하여 결제부터 주문 관리자 처리까지 즉시 확인 가능합니다.
